# Shared source handoff

Start with ../SOURCE-NOTES.md and ../README.md. Current source adds independent custom sprite colours, separate SNES/Genesis edits, stable all-pose palettes, colour-based selection and responsive before/after previews. The Best enables the optional scenery motion, Pride Rock firelight and gradual King sunrise.

The Windows Custom Colours download contains the current tested player and these features. A clean rebuild reproducing the incremental local player is not certified.

Keep frameworks unmodified at ../dependencies.json revisions. Do not commit ROMs, extracted assets, generated game code, settings, saves or recordings. Background changes require per-scene evidence in background-audit.md.
